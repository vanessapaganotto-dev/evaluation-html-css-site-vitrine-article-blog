# Le Globule – Responsive HTML/CSS Website

## Description

Responsive website built with HTML and CSS featuring a classic structure with a main menu including rich dropdown submenus, a two-column main content area, and a simple footer.  
The design uses navigation lists, figures with images and captions, and a semantic organization using header, main, aside, and footer elements.

---

## Features

- Main menu with grid-based dropdown submenus  
- Images with alt attributes for accessibility  
- Main content organized in columns  
- Use of semantic HTML5 elements  
- Responsive layout (via external CSS)

---

## Usage

- Open the `index.html` file in a modern web browser.  
- Navigate using the main menu and its dropdown submenus.  
- Read articles in the main column and complementary sections in the aside.  
- Footer includes additional navigation links.

---

## Technologies Used

- HTML5  
- CSS3 (linked in `../css/default.css` and `css/style.css`)
